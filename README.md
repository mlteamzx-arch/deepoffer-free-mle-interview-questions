## Source preservation

The export includes only entries whose `premium` field is not `true` in DeepOffer's embedded `QUESTIONS` array.

Answer paragraphs are joined in their original order without edits. Original inline HTML and LaTeX formulas are retained. Stored Mermaid diagrams appear in `mermaid` code blocks, and stored follow-up questions appear in separate sections.

The free entries have no separate key-points field, so no key-points sections are added. Company/source labels and source links are copied as stored.
